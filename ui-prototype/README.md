# TradeDesk AI Workbench —— 前端原型（ui-ux-pro-max）

外贸业务员的 AI 数字员工工作台 · 三页可交互原型。**纯静态，双击 `index.html` 即可打开**，无需构建、无需后端。

## 1. 怎么打开

| 页面 | 文件 | 看什么 |
| --- | --- | --- |
| 询盘工作台（主界面） | `index.html` | 三栏：线程看板 / 会话与草稿 / 签核与风控 |
| 运营看板 | `dashboard.html` | 线程漏斗、单位成本、分语种质量、风险事件、闸门运行 |
| 知识库与检索 | `knowledge.html` | 检索管线 7 步、证据块、术语表、评测两层 |

**演示动线（3 分钟讲完全流程）**

1. 打开 `index.html`，右上角「演示场景」依次切 **脚本 A → B → C → D**：
   - **A 英语询价**：草稿带证书编号与有效期，价格/交期停在人审闸门（GATE-01/02）
   - **B 西语跨语种**：西语提问命中中文产品库，术语用标准译
   - **C 阿语 + 受控名单**：**系统什么都不说**，只给风险等级与证据链（GATE-03 默认不放行）
   - **D 歧义追问**：信息不足 → 只追问，不猜价格（置信度 0.41 < 阈值 0.55）
2. 在右栏点「通过并发送 / 修改后通过 / 驳回 / 转交」——状态、审计时间线、待签核数会同步变化
3. 切 `dashboard.html` 看效果如何进入漏斗、成本与门槛卡；切 `knowledge.html` 改「检索基准日」，看法规与证书的时效过滤变化

## 2. 设计系统的来源与关键决策

设计系统由 `ui-ux-pro-max` 生成并持久化在 `design-system/tradedesk-ai-workbench/`（MASTER.md + pages/workbench.md）。

| 项 | 取值 | 决策理由 |
| --- | --- | --- |
| 风格 | Minimalism & Swiss Style | 企业级内部工具：高对比、网格化、信息优先 |
| 密度 | **Density 8/10（密集型工作台）** | 业务员一天看几十条线程，间距 2/4/8/12/16/24/32px |
| 色彩 | **Industrial slate + stock green**（#334155 / #2563EB / #059669 / #DC2626） | **偏离了 MASTER 推荐的 "AI 紫 + 生成粉"**：合规类高密度界面需要冷静中性底色与高对比语义色，紫色渐变会让风险态不刺眼 |
| 字体 | Outfit（拉丁）+ **Noto Sans SC**（中文） | MASTER 的 Outfit/Work Sans 不覆盖汉字，中文界面会回退成系统字体；改用目录里的 "Chinese Simplified" 配对 |
| 动作色 | 单一动作蓝 #2563EB | 一屏只有一个"可点击主色"，避免签核按钮与导航抢注意力 |
| 风险色 | 高=红 / 中=琥珀 / 低=绿 | 红/绿在色觉障碍下不可靠，故同时带文字与图标（不靠颜色单独表意） |
| 图标 | Phosphor 风格线性 SVG（内联，无 emoji） | 目录推荐的图标库；内联避免 CDN 依赖，离线可用 |
| 圆角/阴影 | 8px 圆角 + sm/md 两级阴影 | 密集界面用弱阴影，靠边框而不是投影分层 |

## 4. 可访问性与质量自检（ui-ux-pro-max pre-delivery checklist）

- [x] 无 emoji 图标，全部为内联 SVG（ Phosphor 风格），且为装饰性时标 `aria-hidden`
- [x] 所有可点击元素带 `cursor:pointer`（按钮、chip、线程项、引用条、导航）
- [x] 悬停/状态过渡 180–250ms，无位移型 hover（不用 transform 改变布局）
- [x] 正文对比度 ≥ 4.5:1（石板灰底 + 深色文字；语义色均配文字标签）
- [x] 焦点态可见：`:focus-visible` 2px 蓝色描边 + 2px 偏移；线程列表支持 ↑↓ 键导航
- [x] 尊重 `prefers-reduced-motion`：动画与过渡全部关闭
- [x] 响应式断点 375 / 768 / 1024 / 1440 均验证，390px 下导航转为横向滚动条、无横向溢出
- [x] 表格外层 `.table-wrap` 溢出滚动，sticky 表头
- [x] 状态不只用颜色表达：风险、闸门、语种均带文字或图标

## 5. 已知限制（原型边界）

| 限制 | 说明 |
| --- | --- |
| 纯前端 mock | 所有数据来自 `assets/data.js`，无后端、无真实检索；按钮只改本地状态 |
| 字体需联网 | Outfit / Noto Sans SC 走 Google Fonts，离线时回退到系统字体（中文用微软雅黑/苹方） |
| 主题固定浅色 | 设计系统声明支持深色模式，但当前只实现浅色（合规工作台建议浅色优先） |
| 无 RTL 布局 | 阿语正文已用 `direction:rtl` 渲染，但整个界面未做 RTL 镜像（界面语言始终是中文） |
| 数据为示例 | 买家、公司、价格、指标均为演示值；真实数值口径见 PRD 14.2 |

## 7. 下一轮可以做什么

1. **接真数据**：把 `data.js` 换成 API 调用（`GET /threads`、`POST /threads/{id}/signoff`），UI 结构不用动
2. **拆组件**：现在是三个独立 HTML 重复了侧栏；可抽成 `layout.js` + Web Components，或迁到 React/Vue
3. **补深色模式**：`data-theme="dark"` 下重设令牌
4. **补空态/加载态/错误态**：真实系统里"无引用不可发送""名单库不可用转人工"都需要独立界面
5. **移动端独立设计**：现在是桌面三栏的降级折叠，外勤场景值得单独一版
