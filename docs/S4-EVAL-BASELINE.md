## 四、五条结论（都有数据支撑）

**1. 型号识别只能信结构化通道。**结构化通道 SKU R@1 = 1.000（三个买家语种全额），
而稠密通道 SKU R@1 仅 0.083（en）/ 0.250（es）/ 0.208（ar）。
> 稠密通道的「产品块 R@5」全语种都是 1.000，但「SKU R@1」很低 → **它能找到产品，却分不清是哪个型号**。
这量化了 4b 里的设计决定：稠密通道权重必须最低（RRF k=100），否则会出现「问 X-200 却报 X-300 的价格」。

**2. 稠密通道在阿语上几乎无效。**ar 的「同语产品 R@5」只有 **0.022**（en 0.311 / es 0.644）。
这与第三节实测的相似度矩阵一致（zh↔ar 约 -0.02）。
→ **跨语种能力不能依赖嵌入**，只能靠**四语分块 + 术语表桥接**。

**3. 融合把弱通道兜住了。**三个买家语种的融合 SKU R@5 均为 1.000，
而单独的词法在 ar 上 R@1 仅 0.292、稠密在 es 上 R@5 仅 0.458。RRF 的价值在这里是实现的。

**4. 意图分类（关键词法）远不达 PRD 门槛。**Macro-F1：en 0.68 / es 0.58 / ar 0.63 / zh 0.61（PRD 12.3 门槛：en/es ≥0.90、ar ≥0.85）。
本轮评测**直接暴露了词表缺口**（西语/阿语的物流与投诉词几乎没有）——
已补词表并把「投诉」排在「物流」之前（否则「delivery is late」会被归到物流），
Macro-F1 随之提升（en 0.54→0.68、es 0.38→0.58、ar 0.52→0.63）。但距 PRD 门槛仍有差距 → **关键词分类器到底不行，S5 换真模型才是出路**。

**5. 非产品块（术语/证书/法规）仍是单语 zh，把「同语 Top1」拉低。**
融合通道的同语 Top1：en 0.067 / es 0.178 / ar 0.333——因为 top-1 常是**中文术语块**。
影响有限（对外内容与价格不受影响，因为数值来自结构化规格记录），但是引用的语种标签会不对 → 下一步把证书/法规/术语也按语种建块。
